# Data directory

See **[DATA_INVENTORY.md](DATA_INVENTORY.md)** for the full catalogue.

**Main line (public, already computed):** `external/carlisle/` (Fraehr Figshare dump). Chowilla is the same ingest once downloaded.

**Generator-only (not required):** `external/hecras_merced/` and `external/hecras_bald_eagle/` are USACE tutorials without result HDF.

**Brisbane appendix (Queensland licence):** `raw/` + `metadata/` as below. Do not treat synthetic demo arrays as real hydraulics.

## Raw data (user-provided, Queensland-licensed appendix)

Paper grids are **not** bundled. After you obtain BRCFS / author exports, organise as:

```
data/raw/dem/dem.tif          # optional if terrain is inside HF NPZ
data/raw/hf/FE21.npz          # HF 15 m output grids (30 m computational)
data/raw/lf120/FE21.npz       # LF 120 m (60 m output)
data/raw/lf300/FE21.npz       # LF 300 m (150 m output)
data/raw/lf/                  # optional alias; used only if lf120 is empty
data/raw/auxiliary/           # public extras (not TUFLOW cubes)
```

Required array keys:

- `depth`: float, shape `(n_timesteps, n_cells)` or `(n_cells,)` for max-only
- `terrain` (optional): float, shape `(n_cells,)`
- `shape` (optional): `[ny, nx]` for structured grids

LF files must use the same event stems as HF (`FE1`…`FE51`). Event lists and VE1–VE4 splits: `metadata/events.csv`, `metadata/splits.yaml`.

## Synthetic data

Generated by `scripts/generate_synthetic_data.py` into `data/synthetic/training_events.npz` for development and CI only. Results are **not** representative of Brisbane hydraulics.

## Processed / outputs

- `data/processed/` — interpolated LF-on-HF grids (optional cache)
- `data/metadata/` — paper event catalogue, splits, grid spec, Table 1
- `outputs/models/` — reloadable LSG EOF + GP state
- `outputs/evaluation/` — metric summaries and `pred_examples.npz`
- `outputs/figures/` — plots from `scripts/plot_workflow_results.py`

## How to obtain real Brisbane data

The paper Availability Statement: URBS + TUFLOW are licensed by the Queensland Government. Request BRCFS models via [Business Queensland](https://www.business.qld.gov.au/industries/mining-energy-water/water/maps-data/modelling/brisbane-river-catchment) or `hydrology@detsi.qld.gov.au` (licence fee AUD 821 as of 2026-08-14). Contact Wen Wang (`www1@student.unimelb.edu.au`) for the 51-event export used in the article.

A public **2011 flood-extent polygon** (BCC LGA, CC BY 4.0) is stored under `raw/auxiliary/` as geographic context only. It is not a substitute for HF/LF depth cubes.
